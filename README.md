# Prince Hammond's Portfolio Website

A professional portfolio website built with Vite, JavaScript, and JSON.

## Features

- Multi-page navigation (Home, About, Projects, Blogs, Planner, Games)
- Theme toggle with glassmorphism effects
- Streak setter in Planner
- Simple guessing game
- Data stored in JSON files

## Setup

1. Install Node.js
2. Run `npm install`
3. Run `npm run dev` to start development server
